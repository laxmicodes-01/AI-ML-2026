Strings
Immutable → Strings cannot be changed after creation.
Traversal → Visiting each character of a string one by one.
Slicing → Extracting a part of a string using [start:end:step].
Sets
Unique Values → Sets automatically remove duplicate elements.
O(1) Lookup → Checking if an element exists in a set is very fast on average.
HashMap (Dictionary)
Key-Value Pairs → Data is stored as keys mapped to values.
O(1) Average Lookup → Accessing a value using its key is very fast on average.
